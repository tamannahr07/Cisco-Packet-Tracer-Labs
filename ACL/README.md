# ACL Configuration

## Objective
To configure an Access Control List (ACL) in Cisco Packet Tracer to control network traffic.

## Tools Used
- Cisco Packet Tracer
- Cisco Router
- Cisco Switch
- PCs

## Concepts
- Access Control List (ACL)
- IP Addressing
- Network Security
- Packet Filtering

## File
The Packet Tracer file for this lab is available in this folder.

## Learning Outcome
Learned how to configure and apply ACL rules on a Cisco router to permit or deny network traffic.
